StudySmart AI — Frontend Development Prompt

Build a modern, professional, responsive educational web application called StudySmart AI.

StudySmart AI is designed for secondary-school students and helps them study effectively by explaining topics, generating quizzes, analyzing performance, identifying weak areas, and creating personalized study plans.

Goal

For this first version, focus ONLY on creating the complete frontend user interface.

Do not implement the real AI backend, database, authentication backend, payment system, or file-processing system yet. Use realistic sample/mock data where necessary.

Important Development Requirements

Use reusable components wherever possible.

Keep the UI consistent across all pages.

Use clear typography and accessible contrast.

Add hover effects, loading states, empty states and appropriate error-state designs where useful.

Do not make the application look like a generic AI chatbot.

It should feel like a complete educational platform.

Use realistic sample content instead of placeholder text such as "Lorem ipsum."

The final result should look like a professional startup-quality student learning application.
